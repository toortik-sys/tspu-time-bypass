# Задержка TCP ACK заставит ТСПУ забыть о существовании TCP-сессии ?

**Не знаю, можем проверить.**

Согласно [tspu-docs](https://github.com/DanielLavrushin/tspu-docs), **ТСПУ** помнит сессию ограниченное количество времени.
Идея: задержать часть **TCP** хендшейка, и проверить не успеет ли **ТСПУ** забыть сессию.

Кандидатом на проверку был выбран, разумеется, **youtube.com**

Для первоначальной проверки были использованы **Wireshark** и **Scapy**, результат согласовался с гипотезой: после задержки соединение продолжалось, хотя **ТСПУ**, судя по наблюдениям, уже не учитывало его состояние.

Позже, для удобства, идея была реализована в **Python-скрипте** уже с **WinDivert** в качестве способа перехвата пакетов, так и родился `bypass.py`

## Что потребуется для проверки ?

1. **ОС** `Windows`
2. `pip install pydivert`
3. **Заменить** `ip = "YOUR_LOCAL_ADDR"` **на локальный адрес своего компьютера**
4. Запустить скрипт в терминале **от имени администратора** `python bypass.py`
5. Открыть браузер, открыть в нем **youtube.com**, ждать.

## Результаты

В зависимости от исхода проверки вы либо увидите `TLS Server Hello detected, TLS handshake bypassed`, либо нет

Если увидели это сообщение, значит, в вашей сети задержки в `15` секунд хватило, чтобы соединение продолжилось, а **ТСПУ**, вероятно, забыло состояние сессии. Если сообщение не появилось, можно попробовать увеличить задержку. 
Если же и это ничего не дало: `эксперимент очевидно неу-неудачный`

Перед каждой проверкой закройте браузер, чтобы старые соединения с **youtube.com** не повлияли на результат.

## Ограничения

- Скрипт работает с **IPv4**. **IPv6**/**UDP**/**QUIC** не поддерживаются
- Значение задержки задаётся в `DELAY`. Подходящее время и сам результат зависят от вашего регионального **ТСПУ**
- Скрипт **перехватывает**, **задерживает** и **отбрасывает** часть пакетов для адресов, которые ваш **DNS** считает принадлежащими к **youtube.com** во время работы. Он экспериментальный и может замедлить или прервать соединения.

## Это исследовательский эксперимент, а не универсальная программа обхода блокировок.

## Зачем это?

Да просто по приколу: посмотреть результаты исследования, провести собственный эксперимент и наглядно узнать больше о работе **ТСПУ** и одном из способов обхода блокировок.
